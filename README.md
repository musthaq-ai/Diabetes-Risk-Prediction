# Diabetes Risk Prediction 🏥

A Machine Learning project to predict diabetes risk using patient health data.

## 📊 Dataset
- **Source:** Pima Indians Diabetes Database (Kaggle)
- **Records:** 768 patients | 8 features

## 🤖 Models Used
- Logistic Regression
- Random Forest Classifier

## 📈 Results
| Model | Accuracy |
|-------|----------|
| Logistic Regression | 76.62% |
| Random Forest | 76.62% |

## 🔧 ML Pipeline
- Data preprocessing (zero-value imputation, feature scaling)
- Train/Test split (80/20)
- Model evaluation (Confusion Matrix, Precision, Recall, F1-Score)
- Model saved using Pickle

## 🛠️ Tech Stack
Python | Scikit-learn | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook
